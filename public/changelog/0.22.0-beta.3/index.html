Vorno 0.22.0-beta.3

September 19, 2026 · pre-release

Download 0.22.0-beta.3 & assets →

Bug Fixes

  • Fixed the automation "Run test" button delivering prompts with unexpanded $CRAFT_* variables. A webhook router prompt written against $CRAFT_WEBHOOK_PAYLOAD_PATH reached the model as that literal string and the run ended silently with no report. Test runs now expand variables against the matcher's own event, and webhook matchers get a real staged synthetic payload file to read.
  • Test runs no longer masquerade as real dispatches in automation history. Every test-run record (prompt, webhook, and script actions) is marked and rendered as "Test run — …" in the timeline.
  • A non-POST request to a webhook URL now answers 405 Method Not Allowed with Allow: POST instead of falling through to the API auth gate and answering 401 Missing Authorization header — a route miss no longer reads as a rejected webhook token.
