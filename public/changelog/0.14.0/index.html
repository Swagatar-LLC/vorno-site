Vorno 0.14.0

July 30, 2026

Download 0.14.0 & assets →

Features

  • vorno:// links now open Vorno directly. Vorno registers its own vorno:// URL scheme alongside the existing craftagents:// scheme, using the same link format. Links Vorno generates now prefer vorno://, so they open Vorno reliably even when another Craft Agents build is installed on the same machine. Existing craftagents:// links continue to work exactly as before — nothing you've saved or shared will break.

Bug Fixes

  • macOS Calendar access can now be granted. Vorno declares the Calendar usage descriptions macOS requires, so connecting a calendar source now shows the system permission prompt and Vorno appears under System Settings → Privacy & Security → Calendars. Previously the prompt never appeared and there was no way to grant access. If you were affected, you may need to reinstall this version and relaunch for the prompt to appear.
